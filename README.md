一、项目简介
FOC（Flight Operations Control）航班运行控制系统简易前端 Demo，模拟航空运行指挥中心界面，还原航班监控、基础运行管理等核心场景。项目为纯前端页面，开发周期短，主打快速落地页面布局、视觉风格与基础交互，适用于面试作品展示。

二、技术栈
基础技术：HTML5 + CSS3 + JavaScript
特性：原生代码实现，无复杂框架依赖，代码简洁易读，上手与演示便捷

三、主要功能（简易版）
整体布局：侧边导航栏 + 主内容展示区，复刻航空指挥系统经典布局
页面视觉：采用航空风深色主题，搭配基础样式美化，模拟专业管控界面
基础交互：简单悬浮效果、模块切换、信息展示等基础前端交互逻辑
数据展示：静态模拟航班信息、运行状态、基础数据面板等内容

四、运行方式
下载项目文件，找到 flight-control-foc-demo.html
使用任意主流浏览器（Chrome、Edge、Firefox 等）直接打开该文件即可运行
无需搭建后端、无需安装依赖，开箱即用

五、项目特点 & 开发说明
开发周期：整体耗时 2 天完成，属于轻量化面试演示项目
定位：简易演示版本，仅实现核心页面与基础交互，未做复杂业务逻辑、数据联调及全量功能开发
优势：代码精简、结构清晰，界面风格贴合行业场景，可直观体现前端页面搭建、样式编写与基础交互能力
