一、项目简介

FOC（Flight Operations Control）航班运行控制系统简易前端 Demo，为快速学习行业知识，通过模拟航空运行指挥中心界面，还原航班监控、基础运行管理等核心场景。
项目为纯前端页面，开发周期短，主打快速落地页面布局、视觉风格与基础交互，不适用于具体业务。

基础技术：HTML5 + CSS3 + JavaScript
特性：原生代码实现，无复杂框架依赖，代码简洁易读，上手与演示便捷

三、主要功能（简易版，共9个模块）
1. 航班计划管理

航班计划申报列表，含计划周期 / 航班号 / 航线 / 审批状态多维筛选
支持新增计划申报、查看各节点批复意见
审批流程可视化：民航局审批 → 空管航路审核 → 机场机位评估 → 正式生效
弹窗查看审批详情 / 流程时间轴，支持进度跟踪与空管审核操作

2. 运力 / 飞机排班

当日飞机排班总览，展示执飞飞机号、机型、适航状态、维修限制、换飞审批状态
支持行内展开查看单架飞机完整当日航段链
操作能力：本场换飞机申请、跨场调机申请、航段拆分互换
覆盖典型场景：飞机故障停场、定检临近换机、运力临时调配、局方管控

3. 机组排班管理

机组执勤排班表，含资质状态、执勤时长、休息合规检查
支持机组查询与排班调整操作

4. 情报与气象支撑

全局运行风险总状态看板（正常 / 一般风险 / 高风险三级，颜色预警）
气象信息与航行情报（NOTAM）双轨并行展示
每条情报标注：影响区域 / 详细监测数据 / 风险等级 / 受影响航班清单 / 当前状态
支持生成每日运行气象情报研判报告（含六大章节：风险结论 / 机场分析 / 航路分析 / NOTAM 汇总 / 重点预警 / 运行建议）
支持推送至签派、手动重新研判

5. 飞行签派放行

航班放行列表，含飞机号、机组、气象通告、计算油量、备降场信息
放行状态管理：待放行 / 已放行 / 拒绝放行

6. 实时航班动态监控

在飞航班实时状态跟踪

7. 地面保障协同调度

地面保障资源与任务协同管理

8. 应急处置与运行决策

异常事件应急响应流程与决策支持

9. 运行统计与事后复盘

运行数据统计分析与复盘报告


四、运行方式

下载项目文件，找到 flight-control-foc-demo.html
使用任意主流浏览器（Chrome、Edge、Firefox 等）直接打开该文件即可运行
无需搭建后端、无需安装依赖，开箱即用

五、项目特点 & 开发说明

开发周期：整体耗时 2 天完成，属于轻量化面试演示项目
定位：简易演示版本，仅实现核心页面与基础交互，未做复杂业务逻辑、数据联调及全量功能开发
